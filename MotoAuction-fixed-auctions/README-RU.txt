MotoAuction — обновление чата

Файлы:
- chatbot.js — обновлённый виджет и интеграция с /api/chat
- chatbot.css — стили чата
- server.js — пример серверного API для ИИ
- .env.example — шаблон переменных окружения

Подключение:
1. Добавьте <link rel="stylesheet" href="chatbot.css"> на страницы, где есть чат.
2. Подключите chatbot.js после загрузки DOM (либо оставьте его текущий способ подключения).
3. Запустите серверный пример: npm install express openai dotenv; скопируйте .env.example в .env и задайте OPENAI_API_KEY на сервере; node server.js.
4. Раздавайте сайт и /api/chat с одного origin или настройте прокси на вашем веб-сервере.
5. Не помещайте API-ключ в JavaScript браузера. Для статического сайта без backend ИИ через API работать не будет; локальные ответы требуют настройки aiProvider: 'local'.

Примечание: чат хранит историю локально в браузере, как и прежняя версия. Проверьте бизнес-данные и тексты базы знаний перед публикацией.
